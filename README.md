# VeloxClient-Data

Daten für den [VeloxClient](https://github.com/benhwkoehler-bit)-Launcher:
Versionsliste und die Velox-Performance-Packs (`oneclient/bundles/generated/*.mrpack`).

Erzeugt mit `tools/build_packs.py` aus `pack/mods.json`. Nicht von Hand bearbeiten.

- Die Packs enthalten nur Download-Links und Prüfsummen. Die Mods selbst kommen von Modrinth bzw. CurseForge.
- `oneclient/versions/metadata.json` basiert auf Polyfrosts DataStorageV2 (GPL-3.0).
- VeloxClient basiert auf [OneClient](https://github.com/Polyfrost/OneLauncher) von Polyfrost.
